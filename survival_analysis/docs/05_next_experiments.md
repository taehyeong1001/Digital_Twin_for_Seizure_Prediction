## 0. 예비 진단 (2026-10-13, single node 멤버 0, coarse cohort)

설계 전에 (4)의 가설을 바로 확인할 수 있는 싼 진단 두 개를 돌렸다.

**P1. teacher-forcing 한 스텝 잔차의 자기상관 (ACF)**

| lag (32 Hz 스텝) | 1 | 2 | 4 | 8 | 16 | 32 | 64 |
|---|---|---|---|---|---|---|---|
| 잔차 ACF | 0.002 | 0.008 | −0.012 | −0.001 | 0.010 | −0.002 | 0.003 |
| 신호 ACF | 0.985 | 0.949 | 0.829 | 0.510 | 0.100 | −0.071 | −0.078 |

- 잔차 표준편차는 신호의 9%다. 잔차는 **사실상 백색 잡음**이다.
- 그래서 iid 재표집이 "잔차에 있던 시간 상관"을 버린 것은 아니다. 버릴 상관이 없다.
- 해석: readout이 한 스텝 예측을 잘하면 잔차는 원래 백색에 가까워진다 (innovation).

**P2. 노이즈를 끈 rollout (`innovation_scaling = 0`)**

| x0 | GT 이탈 / 중앙 시각 | RC (노이즈 있음) | RC (노이즈 없음) |
|---|---|---|---|
| −2.1611 | 0/10 | 2/10, 48 s | 0/10 |
| −2.0589 | 10/10, 83 s | 0/10 | 0/10 |
| −2.0443 | 10/10, 69 s | 2/10, 93 s | 0/10 |
| −2.0297 | 10/10, 64 s | 10/10, 16 s | 0/10 |
| −2.0151 | 10/10, 52 s | 10/10, 1.9 s | 0/10 |
| −2.0005 … −1.9275 | 10/10, 36–52 s | 10/10, 0.6–0.9 s | **10/10, 0.6–0.9 s (같음)** |

- 시행 260개 중 236개에서 이탈 여부가 노이즈와 무관하다.
- 큰 x0에서의 "1초 이탈"은 노이즈 없이도 똑같이 일어난다. 즉 **static 입력이 정하는 결정론적 발산**이다.
- 노이즈가 결과를 바꾸는 곳은 좁은 띠(−2.044 ~ −2.015)와 거짓 이탈 하나뿐이다.
  - RC 자체의 전이점은 약 −2.01이고, 노이즈가 이를 약 −2.03으로 옮긴다. GT 전이점은 −2.061이다.
- [04](04_fair_comparison.md) §6의 결과와도 맞는다: 같은 reservoir에서 노이즈만 바꾼 arm B는 A와 거의 같았다.

**→ "time correlation"을 두 뜻으로 나눠서 검증한다.**
- **(i) 짧은 시간 상관:** 주입하는 잔차의 시간 구조. single node에서는 잔차 자체가 백색이라, 이 경로의 효과는 작을 것으로 예상한다. 3-node 잔차는 아직 보지 않았다 (T1).
- **(ii) 느린 시간 척도:**
  - GT는 느린 변수 z(tau0 = 2857) 때문에 λ가 바뀐 뒤 35–100 s에 걸쳐 이탈한다.
  - RC(leak 0.32, 32 Hz)는 기억 시간이 짧다. 게다가 **λ가 고정된 정상 궤적만** 보고 학습했다. 그래서 static이 바뀌면 즉시 새 상태로 뛴다.
  - 3-node는 이탈 궤적(`event_signals`)을 학습에 넣었다. 학습 범위도 안정 경계 바로 아래까지 채웠다. 이 두 가지가 single node와 3-node의 차이를 설명하는 경쟁 가설이다.

## 1. (1)(2) 생존의 두 가지 보기 — 둘 다 λ에 대해 그린다

두 보기는 같은 대상, S(t | λ) = P(이탈 시각 > t | λ)의 서로 다른 단면이다.

| | V1 시간 보기 (지금 방식) | V2 원본 방식 |
|---|---|---|
| 대상 | 곡면 S(t \| λ) 전체 | t = H에서 자른 단면 S(H \| λ) |
| 그림 | (λ, t) heatmap (GT / RC / 차이) + 선택한 λ의 KM 곡선 + **T50(λ)** (중앙 이탈 시각, KM 구간 포함) | λ에 대한 곡선. GT(Jeffreys 95%), A, B, E(멤버 5–95% 띠) |
| 지표 | IBS, D-calibration, T50 오차 | 기존 MAE, Brier(H), x50(H) |
| 연결 | h = 60 / 90 s 단면을 V1 위에 점선으로 표시해 V2와 이어 준다 | |

- **대상:** single coarse / fine, 2-node, 3-node(rate). arm A, B, E.
- **비용:** 이미 저장된 이벤트 시각만으로 그린다. 재분석만 하면 된다.
- **주의:**
  - V2만 보면 single node에서 GT의 확률성이 보이지 않는다 (계단). V1의 T50(λ)가 single node의 핵심 실패인 "1초 이탈"을 바로 보여 준다.
  - T50(λ)는 H 안에서 이탈이 절반 이상인 λ에서만 정의된다. 나머지는 "> H"로 표시한다.

## 1b. 앙상블 활용 방식: seed별 임계값 λc의 분포 (2026-10-13 사용자 제안, 구현·실행 완료)

**아이디어:**
- reservoir 하나 = 원본 실험 하나다. seed j마다 생존 곡선 S_j(h | λ)가 하나 나오고, 거기서 임계값 λc,j가 하나 나온다.
- 그래서 seed 20개 → λc 20개 → **히스토그램**으로 GT λc와 비교한다.
- 시간 축 보기(§1 V1)는 그대로 유지하고 함께 계산한다.

**정의와 기준선:**

| 항목 | 내용 |
|---|---|
| λc 정의 | 원본 코드의 `empirical_x50`과 같다: 생존이 처음 0.5가 되는 점. 정확히 0.5인 점이 없으면 첫 교차를 선형 보간한다. 로지스틱 MLE x50도 함께 계산해 비교한다 |
| 교차하지 않는 seed | 버리지 않는다 (refill 금지와 같은 원칙). 범위 전체에서 S < 0.5면 "below range", S > 0.5면 "above range"로 표시한다 |
| GT | GT 곡선의 λc. 수준 안에서 시행을 다시 뽑는 bootstrap으로 표본 잡음을 잰다. 독립 seed oracle의 λc도 함께 본다 |
| **arm B (잡음만)** | 멤버 0 reservoir 하나 × innovation rollout 20개에서 각각 λc를 구한다 |
| 해석 | 멤버 λc의 퍼짐 = seed 효과 + 표본·노이즈 잡음이다. arm B보다 넓은 만큼이 seed 효과다 |
| single node 데이터 | coarse + fine을 합쳐 한 격자로 쓴다 (57 수준, 수준당 10 또는 20 시행) |

- **코드:** `survival_dist/critical_values.py`. 재분석만 하므로 약 8 s 걸린다.
- **출력:** `outputs/critical_values/<system>/`. 시스템마다 그림 4장이 나온다.
  - `critical_value_hist.png`: h마다 λc 히스토그램
  - `survival_at_horizon_per_seed.png`: V2, seed마다 곡선 하나
  - `survival_time_heatmap.png`: V1, S(t | λ) 곡면과 차이
  - `t50_vs_lambda.png`: V1, 중앙 이탈 시각

**결과 (H 기준; 괄호는 5–95%):**

| | single node (H = 140 s) | 2-node (120 s) | 3-node (120 s) |
|---|---|---|---|
| GT λc | −2.0610 | −2.0406 | −2.0406 |
| 멤버 λc 중앙값 | −2.118 (−2.270, −1.960) | −2.042 (−2.054, −2.031) | −2.054 (−2.064, −2.021) |
| 교차하지 않는 seed | 4 (모두 above range) | 0 | 0 |
| 0.5를 여러 번 지나는 seed (비단조) | **11 / 20** | 0 | 3 |
| 멤버 0 λc | −2.039 | −2.050 | −2.031 |
| 멤버 λc SD / arm B SD | 0.119 / **0.0009** | 0.0069 / 0.0044 | 0.0148 / 0.0102 |
| 분산 중 seed 몫 ≈ 1 − (B SD / 멤버 SD)² | ≈ 1.00 | ≈ 0.60 | ≈ 0.52 |
| GT의 멤버 분포 내 백분위 | 0.45 | 0.55 | 0.75 |
| 로지스틱 vs 경험적 λc 중앙 차이 | 0.024 | 0.001 | 0.005 |

**해석:**

1. **GT λc의 불확실성은 격자 해상도가 정한다.**
   - H에서 GT는 결정론적 계단이라 bootstrap 구간의 폭이 0이다.
   - 2-node와 3-node의 GT λc가 똑같이 −2.0406인 것은, 둘 다 같은 두 격자점(−2.050, −2.031) 사이에서 1 → 0으로 떨어지기 때문이다. 보간하면 그 중간점이 나온다.
   - 따라서 "GT 95% 구간 안의 멤버 수"는 H에서 의미가 없다. 대신 **격자 간격의 절반(다중 노드 ±0.009, single fine ±0.001)**을 GT 쪽 불확실성으로 읽는다.
2. **다중 노드: seed 분포는 GT를 감싸고, 퍼짐의 절반가량은 표본 잡음이다.** ⚠ **§1c에서 정정:** 이 결론은 수준당 8 시행과 첫 교차 규칙 때문이었다. 32 시행과 로지스틱 λc로 보면 퍼짐의 97–99%가 seed 효과이고, seed 분포는 GT에서 비켜 있다.
   - 2-node 중앙값은 GT와 0.001 차이다. 3-node는 0.013 왼쪽(이른 이탈)에 있고, 격자 한 칸보다 작다.
   - 수준당 시행이 8개뿐이라, reservoir 하나의 λc도 rollout 잡음만으로 SD 0.004–0.010만큼 흔들린다 (arm B).
   - 그래서 **seed 히스토그램의 폭을 그대로 "모델 불확실성"으로 읽으면 과대평가**다. arm B 폭을 빼고 읽어야 한다.
   - 3-node 멤버 0(−2.031)은 분포의 오른쪽 끝에 있다. 대부분의 seed는 −2.055 근처다. 04 §6의 홈 어드밴티지와 같은 신호다.
3. **짧은 h에서는 RC의 λc가 GT보다 오른쪽에 있다** (60 s에서 2-node +0.014, 3-node +0.031).
   - RC가 이탈을 늦게 하므로, 짧은 시간 안에서는 더 큰 λ가 필요하다.
   - T50 그림의 "RC가 8–10 s 늦다"(3-node)와 같은 현상을 λ 축에서 본 것이다.
4. **single node: λc 분포 자체가 실패를 보여 준다.**
   - arm B의 SD는 0.0009로 사실상 결정론적이다 (§0 P2와 맞다). 그런데 seed 간 SD는 0.12로 100배 넘게 크다.
   - 20개 중 11개 곡선이 비단조다. 학습 범위 안의 거짓 이탈 때문에 "첫 0.5 교차"가 −2.29 ~ −2.20에 잡힌다.
   - 즉 **single node에서는 seed마다 λc의 정의 자체가 불안정하다.** 로지스틱 λc와 경험적 λc의 차이도 0.024로, 다중 노드(≤ 0.005)보다 훨씬 크다.
   - 시간 heatmap에서도 RC 앙상블은 시간 방향으로 거의 변하지 않는다 (세로 줄무늬). 이탈이 전환 직후에 일어나기 때문이다.
5. **권장:** (→ §1c에서 실행함)
   - 다중 노드에서 seed별 λc를 정보로 쓰려면, 전이 근처 수준의 시행 수를 늘려(예: 8 → 32) arm B 폭을 줄여야 한다. 이 작업은 rollout만 늘리면 되고, GT는 결정론적이라 늘릴 필요가 없다.
   - 그 뒤 "seed 몫"을 다시 잰다.

## 1c. 다중 노드 전이 근처 촘촘한 cohort로 다시 잰 λc (2026-10-13)

**왜:** §1b에서 seed 퍼짐의 절반이 수준당 8 시행의 잡음처럼 보였다. 시행을 늘려 확인했다.

**cohort 구성:**
- max x0 ∈ [−2.08, −1.95], 0.005 간격 27단계 × GT seed 32 = 864 시행 (`run_multinode_ensemble.py --cohort fine`)
- GT seed는 `SEED + 6100…`, 프로필 seed는 `SEED + 6000`이다. 파이프라인과 oracle이 쓰는 seed와 겹치지 않는다.
- RC rollout은 시행마다 GT warmup으로 warm-up하므로, 시행을 늘리면 GT 시뮬레이션도 그만큼 필요하다.
- 실행: 멤버 20개와 arm B 20개를 rate 모델로 돌렸다. 시스템당 약 40분.
- 통과 조건: arm B rollout 0 = 멤버 0 ✔ (두 시스템, 모든 h).

**λc 추정법:**
- 촘촘한 격자에서는 전이 근처 곡선이 0.5 주위를 오르내린다. 그래서 원본의 "첫 교차" 규칙은 가장 이른 흔들림을 잡는다 (3-node에서 18–20 / 20 곡선이 여러 번 교차).
- 그래서 **곡선 전체에 맞춘 이항 로지스틱 x50을 주 추정치로 쓴다**. 첫 교차 그림도 그대로 낸다.
- 그림: `critical_value_hist_logistic.png`

**해석 (§1b의 2번을 정정한다):**
1. **reservoir 하나의 λc는 충분한 시행에서 매우 안정적이다** (arm B SD ≈ 0.001).
   - §1b의 "퍼짐의 절반은 표본 잡음"은 8 시행과 첫 교차 규칙이 만든 결과였다.
   - **seed 간 퍼짐(SD 0.006–0.013)은 거의 전부(97–99%) 실제 seed 효과다.**
2. **seed 분포가 GT에서 체계적으로 비켜 있다.**
   - 2-node는 95%의 seed가 GT보다 오른쪽(늦은 이탈)이고, 중앙값 차이는 +0.009다.
   - 3-node는 두 무리로 갈린다: −2.06 근처와 GT 근처. 중앙값 차이는 −0.011이다.
   - 성긴 test cohort에서는 2-node가 GT를 감싸는 것처럼 보였다(백분위 0.75). 촘촘하게 보니 아니다.
3. **멤버 0(BO가 고른 seed)은 2-node에서 GT와 거의 같다** (−2.0435 vs −2.043). 하지만 전형적인 seed는 아니다. 홈 어드밴티지와 맞는 신호다.
4. **RC 생존 곡선은 λ(max x0)에 대해 비단조로 들쭉날쭉하다.**
   - 이 흔들림은 innovation 방식과 무관하다 (§3 T2 그림).
   - 수준마다 고정된 3차원 프로필(어느 노드가 max이고 나머지가 얼마나 낮은지)에 RC가 GT와 다르게 반응하는 것으로 보인다.
   - max x0 하나로 축을 요약하는 것의 한계다. S 단계 검증 항목에 추가한다.

## 2. (3) 통계량 검증 — 선택 단계부터 RC 출력까지

현재 선택 기준(`feature_ranking`)은 **학습 x0 6개(−2.30 ~ −2.15)** 위에서만 계산한다.
- 점수 = 0.28·|Spearman| + 0.25·R² + 0.20·단조 비율 + 0.17·tanh(SNR/4) + 0.10·(1 − LOO 오차)
- 그다음 Spearman 상관 0.9 이상인 통계는 중복으로 보고 제외한다.
- 그런데 test는 −1.93까지 간다. 즉 **선택된 통계의 성질이 외삽 구간에서도 유지되는지는 검증된 적이 없다.**

| 단계 | 질문 | 방법 | 지표 |
|---|---|---|---|
| **S1. GT 통계 → λ 지도** | 학습 밖(외삽 띠, GT 경계까지)에서도 단조이고 순서가 꼬이지 않나? 선형 지도가 맞나? | GT 안정 궤적을 λ 격자 전체(학습 + 외삽)에서 만들고, 선택된 통계를 계산한다. 경계를 넘은 λ는 이탈 전 구간만 쓴다 | Spearman, 인접 단조 비율, **재구성 오차** z = (s_fit(λ) − s_obs(λ)) / (λ 안의 SD) |
| **S2. 역추정 (식별 가능성)** | 관측 prefix(warmup 길이 20 / 40 s)의 통계로 λ를 되찾을 수 있나? | 선형 지도를 뒤집어 λ̂를 구한다. 창 길이에 따른 통계 SD도 잰다 | λ̂ 오차와 편향, Kendall τ(λ, λ̂), 창 길이별 SD |
| **S2b. 민감도** | static 입력에 관측 잡음이 있으면 생존 예측이 얼마나 흔들리나? | static을 ±1 SD(S2에서 잰 값)만큼 흔들어 rollout한다 | S(H \| λ)와 T50의 변화 |
| **S3. RC 자기 일관성** | RC가 static s(λ)를 받고 만든 궤적이 **그 통계 s(λ)를 실제로 구현하나?** | RC rollout의 이탈 전 정상 구간(처음 5 s 제외)에서 같은 통계를 계산한다. GT 분포 및 입력한 값과 비교한다 | z-score, 순서(Spearman RC 통계 vs λ), 구간별(학습 범위 / 사이 / 외삽) 비교 |
| **S3b. 입력하지 않은 통계** | 입력한 통계만 맞추고 나머지 동역학은 틀리지 않나? | 입력하지 않은 통계(ACF 여러 lag, 지배 주파수, 피크율, PSD L1; 3-node는 노드 간 상관)로 같은 비교를 한다 | 위와 같음. 3-node는 기존 morphology 지표를 재사용한다 |
| **S4. 연결** | 통계 재현 오차가 생존 오차를 설명하나? | λ별, 멤버별로 S3 오차와 Brier/IBS 기여를 짝짓는다 | 순위 상관 |

- **대상:** single node (선택 통계 = permutation_entropy, std), 3-node (9개: 노드별 mean / std / AC1).
- S3는 seed 앙상블 멤버 여러 개에 적용해 seed 강건성도 본다.
- **비용:**
  - S1, S2는 GT 시뮬레이션만 하면 된다 (single은 수 분, 3-node는 수십 분).
  - S3는 궤적이 필요한데, 지금 저장된 것은 이벤트 시각뿐이다. 그래서 rollout을 다시 해야 한다 (학습은 seed로 재현). arm B 정도의 비용이다.

## 3. (4) 시간 상관 가설 — 검증 설계

**가설 H_T:** single node와 3-node의 차이는 잔차 주입이 시간 상관을 반영하지 못하기 때문이다.
- single node는 iid 재표집, 3-node는 block 재표집을 쓴다.

**경쟁 가설:**
- **H_C (학습 범위):** single node는 GT 전이보다 0.09 아래까지만 학습했다. 3-node는 안정 경계 바로 아래까지 학습했다.
- **H_E (이탈 궤적):** 3-node는 이탈 궤적으로 이탈 동역학을 학습했다. single node는 정상 궤적만 봤다.
- **H_S (느린 시간 척도):** static을 바꾸는 즉시 반응하는 RC 구조 자체의 문제다. ramp, 기억 시간과 관련된다.

| 실험 | 내용 | 재학습 | H_T가 맞다면 예상되는 결과 | 비용 |
|---|---|---|---|---|
| **T0** | single 잔차 ACF, 노이즈 끈 rollout | 없음 | — | **완료 (§0)**: 잔차는 백색이고, 큰 λ의 이탈은 노이즈와 무관하다 |
| **T1** | 3-node 잔차 ACF (시간 + 노드 간 교차상관) | 없음 | 잔차에 뚜렷한 시간 상관이 있다 | 수 분 |
| **T2** | **innovation 방식만 바꾼 rollout** (W_out 고정). 3-node: block(현재) / `iid_original` / `iid_fullrate` / none (코드에 이미 있다). single: iid(현재) / block(이식) / none | 없음 | 3-node를 iid로 바꾸면 V1 / V2 / IBS가 single node처럼 나빠진다. single에 block을 넣으면 좋아진다 | 조건당 arm B 정도. 멤버 5개 |
| **T3** | 학습 내용을 바꿔 2×2 요인 실험: 이탈 궤적 포함 여부 × 학습 범위(경계 근처 / 멀리). single은 둘을 추가하고, 3-node는 둘을 뺀다 | **있음** (하이퍼파라미터는 고정) | H_T가 맞다면 T3의 효과는 작아야 한다. 효과가 크면 H_C / H_E가 맞다 | 조건당 수십 분 (멤버 5개) |
| **T4** | 느린 시간 척도: single node `--ramp-steps`(원본에 있는 옵션)로 static을 천천히 바꾼다. 닫힌 루프(autonomous)에서 k-step 오차의 ACF를 GT 앙상블 퍼짐과 비교한다 | 없음 | — (H_S 검증) | 수 분 |

- **판정 규칙 (미리 정해 둠):**
  - T2에서 innovation 방식을 바꿔도 V2 / IBS의 짝지은 차이 CI가 0을 포함하면 H_T를 기각한다 (생존 예측에 대해).
  - T3 / T4의 효과가 T2보다 크면, 차이의 주원인은 학습 내용이나 시간 척도다.
- **3-node에서 block을 쓴 원래 이유는 정상 피크의 형태(morphology)였다** (README). 생존과의 관계는 원본에서 검증되지 않았다. 그래서 T2는 S3b(형태)와 생존을 함께 본다. block이 형태만 개선하고 생존에는 영향이 없을 수도 있다.
- **T3의 주의점:** 하이퍼파라미터는 원래 조건에 맞춰 튜닝된 것이다. 재학습 조건이 성능 차이를 낼 때 "조건 효과"와 "튜닝이 안 맞는 효과"가 섞인다.
  - 완화책: 멤버 5–10개의 분포로 보고한다. 필요하면 조건마다 작은 BO(24회)를 한다.

**판정 (미리 정한 규칙):**
- **H_T(잔차 시간 상관이 single과 3-node 차이의 원인)는 생존 예측에 대해 기각한다.**
  - 3-node에서 시간 상관을 없애도(iid_fullrate) H 시점 Brier와 λc는 변하지 않는다 (Δλc 0.001 ≪ seed SD 0.013).
  - 시점 정확도(IBS)만 약 9% 나빠진다.
  - single에 block을 넣어도 아무 변화가 없다 (잔차가 백색이니 당연하다).
  - single과 3-node의 차이(Brier 0.32 vs 0.085, λc SD 0.08–0.12 vs 0.013, 이탈 시각 1 s vs 50 s)는 이것으로 설명되지 않는다.
- 노이즈의 **존재(크기)**는 중요하다. 노이즈를 끄면 single은 전반적으로 나빠지고, 3-node는 시점(IBS)이 31% 나빠진다.
- 3-node의 기존 MAE는 노이즈를 줄일수록 오히려 좋아진다 (iid −0.029, 없음 −0.047). 노이즈가 전이 아래쪽에서 거짓 이탈을 만들기 때문으로 보인다. 지표마다 방향이 다르니, block의 득실은 "시점 vs 수준별 빈도"의 교환으로 읽어야 한다.

**남은 경쟁 가설 — 새 단서:**
- BO가 고른 **leakage rate는 다중 노드 0.01(탐색 하한) vs single 0.316**이다.
  - 32 Hz에서 reservoir 시간상수는 약 3 s vs 약 0.1 s로, 30배 차이다.
  - spectral radius도 0.81 / 0.58 vs 0.54다.
- single의 "static 전환 후 1초 이탈"과 다중 노드의 "50초 이탈"은 이 시간 척도 차이(H_S)와 직접 맞닿아 있다.
- 따라서 **(ii) 느린 시간 척도**가 사용자가 말한 "time correlation"의 실체일 가능성이 가장 크다.
- 다음 실험: T4에 single node leak sweep을 추가한다.
  - leak ∈ {0.316, 0.1, 0.03, 0.01}, 다른 하이퍼파라미터는 고정하고 재학습만 한다. readout만 다시 맞추면 되므로 BO는 하지 않는다.
  - 효과가 크면 H_S다. 그다음 H_C / H_E(학습 범위, 이탈 궤적)를 T3로 분리한다.
